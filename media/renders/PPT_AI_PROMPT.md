# 키친모션 발표 슬라이드 개선 요청 (이미지 14장 첨부)

## 프로젝트 요약
- 프로젝트명: **키친모션 (Kitchen Motion)** — 소상공인의 반복 주방 작업을 위한 4자유도 양팔 로봇.
- 대회: 2026 YU 창의적 종합설계 경진대회, 영남대학교. 팀: 전성빈(제어·학습 시스템), 이규홍(그리퍼·구조 해석), 박종진(기구 보완·실험).
- 핵심 흐름: **사람의 시연(리더-팔로워 텔레오퍼레이션) → 영상·관절 데이터 결합 → 개인 서버에서 작업별 모방학습 → 로봇 적용**.
- 현재 구현 완료: 직접 설계한 4자유도 팔(링크 180/130/100 mm, PLA tough 트러스 리브), ANSYS 하중 해석 기반 모터 선정(XM430-W210, XL430-W250), TPU 95A Fin-Ray 유연 그리퍼(랙·피니언 개폐), 축소 조리 도구(미니 프라이팬) 제작, **리더(XL330-M288, OpenRB-150) → 팔로워(XL430/XM430, OpenCR) 실시간 텔레오퍼레이션**, **Isaac Sim 디지털 트윈**(URDF 모델이 실물 팔로워와 동시에 움직임), Isaac Sim 주방 학습 환경 구성.
- 다음 단계(아직 미완료): 영상 동기 수집, 모방학습 정책 학습, 자율 작업 수행.

## 표기 주의 (반드시 지켜 주세요)
- 03~06(병렬 장면)은 **Isaac Sim에서 구성한 학습 환경의 연출 렌더**입니다. "학습 완료", "학습 결과", "성공률" 같은 문구를 붙이지 마세요. 적절한 캡션 예: "Isaac Sim 병렬 학습 환경 구성(100개 인스턴스)", "주방 작업 환경 9개 병렬 인스턴스".
- 07~14(파지 시퀀스 포함)도 시뮬레이션 렌더입니다. 캡션에 "Isaac Sim" 또는 "시뮬레이션"을 명시하세요. 실물 파지 사진은 별도로 제공됩니다.
- 수치(비용 절감률, 성공률 등)를 새로 만들어 넣지 마세요. 기존 슬라이드의 수치만 사용하세요.

## 디자인 요청
- 톤: 이미지의 색을 따라 **밝은 배경 + 로열 블루(#1552E6 근처) 포인트**, 보조색 라이트 블루·차콜. 기존 슬라이드보다 여백을 넓게, 텍스트는 줄이고 이미지를 크게.
- 표지: 07 또는 04를 전면 배경으로 쓰고 제목 "키친모션 — 소상공인의 반복 작업을 위한 4자유도 양팔 로봇"을 왼쪽 정렬로 크게.
- 슬라이드 08(텔레오퍼레이션·Isaac Sim): 왼쪽 "리더 → 팔로워 → 시뮬레이션" 3단 흐름, 오른쪽에 01 또는 02를 크게. 하단 한 줄: "실물 팔로워의 관절 각도가 UDP로 전송되어 Isaac Sim 모델이 실시간으로 같은 자세를 취함".
- 슬라이드 06(Fin-Ray 그리퍼): 09를 오른쪽 절반에 크게, 왼쪽에 기존 해석 수치(변위 5 mm, 반력 2.15 N, TPU 95A HF).
- 슬라이드 07(작업 공간): 10·11·12 3컷을 가로로 나열하고 아래에 "접근 → 파지 → 들기" 라벨, 14 탑뷰를 작게 보조로.
- 슬라이드 09(향후 개발): 05 또는 03을 배경으로 쓰고 "시뮬레이션 병렬 환경에서 정책 검증 → 실물 적용" 흐름을 오버레이. 반투명 어두운 그라데이션을 깔아 글자 가독성 확보.
- 슬라이드 10(시연 영상): 영상 자리 옆에 13을 스틸 컷으로 배치.
- 모든 이미지는 원본 비율(16:9) 유지, 잘라내기는 좌우만. 이미지 위 텍스트는 최소화.
- 폰트: 제목은 굵은 산세리프(Pretendard 또는 Noto Sans KR Bold), 본문은 Regular. 한 슬라이드 본문 60자 이내.

## 산출물
- 기존 11장 구성(표지, 전체 시스템, 4축 설계 근거, 기구 설계, 모터 선정, Fin-Ray 그리퍼, 작업 공간·도구, 텔레오퍼레이션·Isaac Sim, 향후 개발, 시연 영상, 팀 구성)을 유지하되 위 이미지를 배치해 재디자인.
- 16:9, 발표 5분용. 슬라이드마다 발표자 노트에 1~2문장 핵심 멘트 추가.
